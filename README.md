# Horse
The Horse Discord bot

## Horse Features:
- General responses to messages
- Dice roller
- Gambling
- A "score" system
- Random messages
- A "confess" system
- Play YouTube audio in VCs
- A "compatibility" system
- Random responses pulled from Wikipedia
- Various easter eggs

## Future Plans:
- More responses
- Performance upgrades -- As of now, Horse is very unoptimized.

Much of this was coded late at night. Keep in mind that bugs may be frequent, and I am open to any form of help. Report bugs as they appear
